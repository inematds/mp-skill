🛠️ Skills For Real Engineers

Curso em PT-BR sobre as skills do Matt Pocock para Claude Code — fundamentos, workflow e exemplos práticos para engenheiros que querem parar de brigar com o agente e começar a colher resultado.

Começar pela Trilha 1: Fundamentos → Saber mais

Por que skills existem

Skills são pacotes de instruções carregadas sob demanda que o Claude Code (ou Codex) ativa só quando o contexto pede. Em vez de empilhar regras gigantes no system prompt e torcer pra elas serem seguidas, você descreve a habilidade uma vez, em um lugar, e o agente carrega quando precisa.

O Matt Pocock formalizou esse padrão pra resolver quatro dores muito específicas que todo engenheiro que usa LLM com seriedade encontra. Cada uma delas vira um módulo da trilha.

Os 4 problemas que skills resolvem

1

Desalinhamento

O agente faz quase o que você quer, mas com convenções erradas: nomes de variável, estilo de teste, padrão de commit. Skills travam o "como" antes do agente decidir sozinho.

2

Verbosidade

Você reexplica as mesmas regras toda sessão. Uma skill bem-feita mata esse loop — basta o trigger certo e ela carrega tudo de uma vez.

3

Código quebrado

O agente gera código que parece certo mas não roda — falta validação, falta type check, falta o passo de teste. Skills codificam o checklist de qualidade.

4

Ball of mud

CLAUDE.md vira um arquivão de 2000 linhas, ninguém lê inteiro e nada é seguido. Skills quebram esse monolito em peças carregadas só quando relevantes.

Para quem é este curso

👥 Público-alvo

  • • Engenheiros usando Claude Code ou Codex no dia a dia
  • • Time líderes que querem padronizar workflow com LLM
  • • Quem já tentou CLAUDE.md e ficou frustrado com o resultado

📋 Pré-requisitos

  • • Conta no Claude Code (ou Codex CLI) instalada
  • • Confortável com linha de comando e Git
  • • Já ter feito ao menos uma sessão real com agente

🎯 O que você vai aprender

  • • Anatomia de uma skill: SKILL.md, triggers, escopo
  • • Como escrever descrições que disparam no momento certo
  • • Workflow do Matt: do esboço à skill publicada
  • • Exemplos reais: handoff, code review, debugging
